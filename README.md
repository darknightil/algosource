# AlgoSource

Сборник алгоритмов, структур данных и техник для олимпиадного программирования (и не только).

В репозитории хранятся конспекты с объяснением алгоритмов и их реализации на C++.

## Структура

Темы разделены на 16 разделов:

- [`asymptotics`](asymptotics/) - асимптотический и амортизационный анализ алгоритмов
- [`cpp_tricks`](cpp_tricks/) - трюки и структуры, упрощающие жизнь в олимпиадном программировании на языке C++
- [`decompositions`](decompositions/) - различные декомпозиции
- [`dp`](dp/) - динамическое программирование
- [`ds_and_queries`](ds_and_queries/) - структуры данных и задачи на запросы
- [`games`](games/) - теория игр
- [`general`](general/) - общие алгоритмы и техники
- [`geometry`](geometry/) - геометрия
- [`graphs`](graphs/) - графы
- [`higher_maths`](higher_maths/) - высшая математика (преимущественно линейная алгебра, FFT, NTT)
- [`maths`](maths/) - алгоритмы теории чисел, комбинаторики и др.
- [`num_and_rand_methods`](num_and_rand_methods/) - численные методы и неточки (рандомизированные алгоритмы)
- [`recursion`](recursion/) - рекурсия
- [`search`](search/) - поиски (бинарный, тернарный и т.п.)
- [`sorting`](sorting/) - сортировки
- [`strings`](strings/) - строковые алгоритмы

В каждой из этих папок находятся подпапки:
- `materials/` — конспекты в формате LaTeX
- `implementations/` — реализации на C++
